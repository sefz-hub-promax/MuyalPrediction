# ניחוש בחירות משפחתי

אתר קטן שבו כל המשפחה ממלאת ניחושי מנדטים, מזינה את התוצאות בליל הבחירות ורואה טבלת דירוג חיה.
כל מי שיש לו את הקישור יכול לערוך, בלי הרשמה. כמה אנשים יכולים לערוך במקביל, וכל שינוי מופיע אצל כולם מיד.

האתר עצמו סטטי (GitHub Pages), והנתונים נשמרים ב־Supabase (חינם).

## הקמה (פעם אחת, כ־10 דקות)

### 1. יוצרים פרויקט Supabase
1. נכנסים ל־<https://supabase.com> ונרשמים (אפשר עם GitHub).
2. **New project** → בוחרים שם (למשל `elections`), סיסמה למסד הנתונים (לא נצטרך אותה) ואזור קרוב (למשל Frankfurt).
3. מחכים דקה־שתיים עד שהפרויקט מוכן.

### 2. מריצים את הסכמה והנתונים
1. בתפריט הצד: **SQL Editor** → **New query**.
2. מעתיקים את כל התוכן של `supabase/schema.sql`, מדביקים ולוחצים **Run**. צריך לראות `Success`.
3. (רשות) אם יש לכם `supabase/seed.sql` מקומי עם נתוני ההתחלה, מריצים גם אותו. הקובץ לא נמצא במאגר בכוונה, כי יש בו שמות. אפשר גם פשוט להוסיף מנחשים ומפלגות דרך האתר.
4. בדיקה: ב־**Table Editor** אמורות להופיע הטבלאות `parties`, `guessers`, `results` עם הנתונים.

> אפשר להריץ את שני הקבצים שוב בלי נזק. `seed.sql` לא דורס שורות שכבר קיימות.

### 3. מעתיקים את פרטי החיבור ל־`config.js`
1. ב־Supabase: **Project Settings** → **API** (או **Data API** / **API Keys**).
2. מעתיקים את **Project URL** (נראה כמו `https://abcdefgh.supabase.co`).
3. מעתיקים את המפתח הציבורי: **anon public** (או **Publishable key**, שמתחיל ב־`sb_publishable_`).
   **לא** את `service_role` / `secret`!
4. פותחים את `config.js` ומחליפים:

```js
window.APP_CONFIG = {
  SUPABASE_URL: 'https://abcdefgh.supabase.co',
  SUPABASE_ANON_KEY: 'eyJhbGciOi...'
};
```

המפתח הזה ציבורי מלכתחילה, ומותר שיופיע בקוד. ההרשאות נקבעות במדיניות (RLS) שב־`schema.sql`.

### 4. מעלים ל־GitHub
1. יוצרים מאגר חדש ב־GitHub (למשל `elections`). אפשר ציבורי או פרטי.
2. מהתיקייה הזאת:

```bash
git init
git add .
git commit -m "Family election guess"
git branch -M main
git remote add origin https://github.com/<שם-המשתמש>/elections.git
git push -u origin main
```

### 5. מפעילים את GitHub Pages
1. במאגר: **Settings** → **Pages**.
2. תחת **Build and deployment** → **Source** בוחרים **GitHub Actions**.
3. עוברים ללשונית **Actions**. אם ההרצה הראשונה נכשלה כי Pages עוד לא היה מופעל, לוחצים **Re-run all jobs**.
4. אחרי דקה האתר זמין בכתובת `https://<שם-המשתמש>.github.io/elections/`. את הקישור הזה שולחים למשפחה.

כל `git push` ל־`main` מעדכן את האתר אוטומטית.

## בדיקה מקומית
פותחים את `index.html` דרך שרת קטן (לא בלחיצה כפולה):

```bash
npx http-server -c-1
```

ונכנסים ל־<http://localhost:8080>.

## איך זה עובד
- כל תא נשמר בנפרד דרך פונקציה במסד הנתונים (`set_guess` / `set_result`) שמעדכנת רק את התא הזה. לכן שני אנשים שעורכים באותו זמן לא דורסים זה את זה.
- השמירה אוטומטית, כ־0.7 שניות אחרי שמפסיקים להקליד. בפינה מופיע "שומר…" ואז "✓ הכול שמור".
- אם אין אינטרנט, השינוי נשאר על המסך ומסומן באדום. לוחצים על ההודעה כדי לנסות שוב (או שזה קורה לבד כשהחיבור חוזר).
- שינויים של אחרים מופיעים מיד, בלי רענון, ולא מזיזים את הסמן ממה שאתם מקלידים.

## שימו לב
- כל מי שיש לו את הקישור יכול לערוך ולמחוק. זה בכוונה (משחק משפחתי), אז לא לפרסם את הקישור ברבים.
- גיבוי: ב־Supabase, ב־**Table Editor**, אפשר לייצא כל טבלה ל־CSV.
- פרויקט חינמי ב־Supabase נכנס להשהיה אחרי שבוע בלי שימוש. אם האתר מפסיק לעבוד, נכנסים ל־Supabase ולוחצים **Restore project**. כדאי להיכנס לאתר כמה ימים לפני הבחירות כדי לוודא שהוא ער.
